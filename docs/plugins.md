# Плагины Mayori

Откройте штатные **Настройки → Mayori → Плагины**. Каждый переключатель управляет отдельной возможностью; выбирать другой пресет или менять инструкции ведущего не требуется.

| Переключатель | Инструмент модели | Назначение |
|---|---|---|
| Кости | `rollDice` | Свободные броски по формулам |
| Проверки | `resolveCheck` | Проверки, криты, урон и последствия по профилям правил |
| Подробности бросков | `getRollDetails` | Полная сохранённая развёртка по `rollId` |

По умолчанию включены все три возможности, как в прежней полной композиции. Их можно выключать независимо, вплоть до игры без инструментов. Настройки относятся ко всему профилю Mayori, сохраняются в профильном `cordis.patch.yml` через штатный DSH Settings API и восстанавливаются после перезапуска.

Изменения действуют в новых и существующих чатах Mayori. Пока ведущий отвечает, ранее предложенные инструменты остаются доступными; сохранённые переключения применяются, когда все текущие ответы Mayori завершатся. Интерфейс показывает отложенное применение. Другие пресеты и корневой Host не получают игровые инструменты.

Инструкции ведущего остаются общими. В следующий запрос модели попадают только схемы включённых инструментов. Реальные наборы инструментов сохраняются штатным журналом запросов; результаты бросков уже записаны в `tool/result`, поэтому переключение не меняет прошлые результаты и не выполняет броски заново.

## Зависимости

Проверки используют Dice provider для настоящих случайных исходов автоматически. Выключенные «Кости» убирают `rollDice` из контекста модели, но не мешают проверкам. Если выключены и кости, и проверки, Dice provider выгружается.

Чтение подробностей независимо от генераторов: его можно оставить включённым для старых бросков. При его выключении полные результаты остаются в журнале и в карточках интерфейса, но модель не получает инструмент чтения.

Регистрация и удаление providers, consumers, маршрута и страницы настроек привязаны к Cordis effects. `PluginSettingsService` определяет контракт; `PersistentPluginSettingsProvider` читает валидируемые volatile Config поля; scope consumer монтирует независимые Dice, Rules и RollHistory. Browser consumer использует same-origin маршрут `/mayori/plugins` и публичный слот `settings.section`.

## Настройка развёртывания

Страница поддерживает клавиатуру и светлую/тёмную тему. На узком экране навигация штатной панели переносится наверх только при открытой странице Mayori; остальные страницы используют оформление DSH.

Поля `dice`, `rules` и `rollHistory` строки `mayori-plugin-settings` — boolean. UI использует revision fence: устаревшая форма не перезаписывает изменения другого окна. Некорректные значения не сохраняются.

Лимиты Dice и профили Rules задаются валидируемым Config entry `dsh-mayori/optional-plugins` внутри общего изолированного group единственного `preset-mayori`: вложенные поля `dice` и `rules`. Они не являются переключателями UI. При переопределении композиции сохраняйте весь список и его идентичность. Независимые публичные entries `dsh-mayori/dice`, `/rules` и `/roll-history` также доступны для собственных композиций; Rules требует `mayoriDice`, у Dice `exposeTool: false` оставляет только provider.

`dsh-mayori/mechanics` сохранён для совместимости. Встроенный Mayori его не использует. Форматы журналов и исторические идентификаторы сохранены.

После изменения wiring установите checkout во временный профиль и проверьте `--dump-config`. `scripts/plugin-settings-smoke.js` проверяет все восемь сочетаний в одном уже начатом чате: фактические схемы запросов, общие инструкции, изоляцию и чтение исходных записей.
