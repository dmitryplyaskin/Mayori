# Сжатие истории

В **Настройки → Mayori → Плагины** включите **Сжатие истории**. По умолчанию оно выключено. Плагин добавляет инструмент `compactHistory` и автоматически заменяет старую часть модельного контекста кратким изложением при заполнении окна. Исходные события, сообщения и результаты бросков остаются в журнале чата. Выключение удаляет инструмент и останавливает дальнейшее сжатие, но не разворачивает уже созданные изложения.

## Настройки

Настройки относятся к профилю Mayori, сохраняются штатным DSH Settings API и восстанавливаются после перезапуска. Инструкции ведущего во вкладке **Пресеты** не меняются. Пока ведущий отвечает, изменения ждут завершения текущих ответов, затем применяются к существующим и новым чатам.

| Поле | По умолчанию | Назначение |
|---|---|---|
| Порог заполнения контекста | 80% | Доля полного окна текущей модели; целое число от 1 до 99 |
| Оставлять последние сообщения | 16% | Доля окна за вычетом резерва обычного ответа, сохраняемая дословно; от 0 до 98, строго меньше порога |
| Инструкция сжатия | Игровое изложение | Редактируемая инструкция: сведения, язык и формат; от 1 до 32768 символов |
| Лимит ответа для изложения | 4096 токенов | Включает размышления, если их учитывает модель; от 1 до 65536 |
| Дополнительный запас контекста | 8192 токенов | Резерв сверх места для обычного ответа; от 0 до 65536 |

При окне `W`, резерве обычного ответа `O` и дополнительном запасе `B` фактический порог — `floor(min(W × thresholdPercent / 100, W − O − B))`. Поэтому сжатие может начаться раньше заданного процента. Последние сообщения сохраняются в бюджете `floor((W − O) × retainPercent / 100)`; граница не разрывает шаг с вызовом инструмента и его результатом. Штатный token meter оценивает токены: порог не является точным сетевым счётчиком провайдера.

Для модели с небольшим окном уменьшите запас и лимит ответа. Если резерв исчерпывает окно либо хвост не помещается ниже порога, DSH сообщает ошибку конфигурации для этой модели и не выполняет плановое сжатие. При подтверждённой ошибке переполнения штатный движок может выполнить более сильное сжатие без обычного сохранения хвоста и повторить запрос.

Поля формы сохраняются кнопкой **Сохранить настройки сжатия**. Переключатели возможностей не сохраняют незавершённый текст формы. **Вернуть игровую инструкцию** меняет только черновик: затем сохраните его. Ошибка сохранения оставляет черновик; устаревшая revision не перезаписывает настройки другого окна.

## Инструкция и журнал

Начальная инструкция сохраняет текущую сцену, отношения, события и решения игрока, открытые сюжетные линии, точные данные и предпочтения. Она запрещает придумывать события и случайные исходы. Пользователь может изменить её структуру и язык целиком. Макросы вроде `{{user}}` передаются буквально.

Service Definition — штатный `CompactionEngine`; Provider — `RoleplayCompactionProvider`, наследующий `BasicCompactionEngine` и заменяющий только документированный `summarize()` hook; Consumers — штатные listeners давления/переполнения, инструмент `compactHistory`, prepended consumer снимка настроек и форма Mayori. Provider изолирован через `isolate.compaction`. Регистрации принадлежат Cordis fiber и удаляются при отключении.

Перед запросом consumer записывает стандартный `user/message` с source `mayori-compaction-settings`: content пустой, source snapshot содержит точные настройки и инструкцию. DeepSeek не отправляет пустые user messages в модельный вход; вкладка «Контекст запроса» также их исключает. Неизменный снимок не дублируется; изменённый заменяет предыдущий активный снимок. Summarizer читает инструкцию из журнала и делает отдельный запрос к текущей модели с `purpose: compaction`. Настройка не становится инструкцией основного ведущего. Снимки и результаты наследуются при native fork и остаются после редактирования настроек. Старые текстовые уведомления очищаются через новые surface replacements при следующем ходе; исторические запросы не переписываются.

В пустом чате consumer передаёт первый снимок в `PreStepDecision.messages`: DSH сам записывает его после защищённого системного префикса. Сжатие накопившейся истории проверяется перед последующими запросами; сообщение игрока из очереди ещё не входит в оценку давления на этом шаге.

DSH сохраняет `compaction/start`, `compaction/summary`, заменяющий `user/message` с `<compacted-summary>` и `compaction/end` в том же постоянном session log. При возобновлении контекст восстанавливается без повторного вызова суммаризатора. «Текущий сохранённый контекст» в Trajectory показывает результат замены, «Полный журнал» сохраняет исходные события.

Пустой ответ, незавершённое изложение, запрос инструмента, изображение или изложение, которое не уменьшает выбранный диапазон, не заменяет историю. Ошибку планового сжатия сообщает штатный движок, после чего пробует продолжить ход. Отдельный pruner Mayori не подключает.

Изложение может пропустить детали или ошибиться. Оно не заменяет структурированное состояние кампании и не даёт модели автоматического доступа ко всем старым сообщениям. Точные результаты бросков остаются доступны через **Подробности бросков**. Системная инструкция и схемы инструментов не сжимаются: если один этот префикс превышает выбранный порог, сжатие не сможет уменьшить контекст до него.

## Инструмент модели

В Tools появляется `compactHistory` без аргументов. Ведущий может вызвать его по просьбе игрока или на границе сцен, даже если автоматический порог ещё не достигнут. Инструмент выбирает старую завершённую часть истории с учётом настроенного бюджета последних сообщений и передаёт диапазон в штатный `CompactionEngine.compactRegion()`. Текущий ход, защищённый системный префикс и целые пары инструментов остаются дословно. Если завершённая история целиком помещается в сохраняемый бюджет, ответ содержит `status: unchanged` без запроса суммаризатора. Успешный ответ содержит `status: compacted` и количество заменённых сообщений; само изложение уже находится в контексте и не дублируется в результате инструмента.

## Собственная композиция

Публичный entry `dsh-mayori/compaction` требует `llm`, `tokenMeter`, `sessions` и использует перечисленные поля как валидируемый Config. При доступном `tools` он регистрирует `compactHistory`. Изолируйте `compaction`, если другой preset уже монтирует provider. Встроенный Mayori монтирует его через persistent preferences; ручная команда `/compact` этим entry не добавляется.

Проверки: `pnpm run check`; `scripts/compaction-smoke.js` в отдельном DSH profile с тестовым probe проверяет реальный порог, инструмент ниже порога, отсутствие служебного текста, сохранённую инструкцию, исходные события, изменение настроек, выключение, replay и fork. `scripts/browser-compaction-smoke.js <URL-test-Host> <manualId> <output-directory>` проверяет четыре схемы в нативном Tools и чистый контекст запроса. Для composition изменений также проверьте `--dump-config`.
