# Язык интерфейса

Откройте **Настройки Mayori → Основные → Язык** и выберите **Русский** или
**English**. Интерфейс меняет язык сразу, без перезагрузки. Выбор общий со
штатным полем **Settings → General → Language** в DSH.

На локальном сервере DSH сохраняет выбор в настройках профиля: он действует
после перезагрузки страницы и перезапуска. При удалённом подключении применяется
штатная политика DSH: выбор остаётся в текущем процессе. Если язык ещё не выбран,
DSH использует поддерживаемый язык браузера, затем английский.

Переводятся главная, галерея, история, персоны, пресеты, настройки Mayori,
действия и подсказки чата, карточки бросков и проверок, контекст запросов,
ошибки и уведомления Mayori. Даты и числа используют выбранный язык.
Русский пакет также переводит штатные элементы боковой панели, основные
элементы ввода и отображения чата DSH, журнал запросов, меню команд, выбор
моделей и настройку их провайдеров. Дополнительные панели и плагины DSH
используют собственные словари; отсутствующий русский перевод заменяется
английским.

Язык интерфейса не переводит имена, карточки, персоны, инструкции, сообщения,
авторские приветствия или сохранённые результаты инструментов. Язык ответа
модели определяется сообщениями и выбранными инструкциями.

## Для разработчиков

`src/features/localization/client/service.js` определяет browser Service
Definition; `DshLocalizationProvider` потребляет публичный `ctx.locale`.
Настройки и browser views — Consumers. Регистрация русского языка, словарей и
привязки helpers принадлежит `ctx.effect`, а сервис предоставляется через `ctx`.
Модельного контекста и второго хранилища языковых предпочтений нет.

Словарь `shared/en.js` использует исходную русскую строку как ключ; русский
словарь выводится из тех же ключей. Используйте `tr(key, { p1, p2 })` для текста
интерфейса. Значения подставляются без перевода. Списки подписей вычисляйте при
рендере, а slot labels регистрируйте как функции, чтобы смена языка работала
без перезапуска. DSH обновляет slot outlets по revision своего locale service.

`noticeText` предназначен только для ошибок и уведомлений продукта, в том числе
Host validation и импортов. Не передавайте в него пользовательский текст.
Host и shared validators сохраняют исходные сообщения; перевод выполняется
при отображении. `native-ru.js` расширяет публичные пространства DSH, не меняя
их реализацию. Новые ключи проверяются тестами на полноту английского словаря
и совпадение подстановок.

Проверки: `pnpm run check`, временная установка с `--dump-config` и
`node scripts/browser-localization-smoke.js <URL-тестового-профиля> [output-directory]`.
